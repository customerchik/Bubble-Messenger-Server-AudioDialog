# Bubble Audio Dialog

## Назначение

Микросервис для взаимодействия пользователей через аудиозвонок в проекте [Bubble](https://github.com/customerchik/Bubble-Messenger-Server).

Используется для создания, ручного и автоматического удаления аудиодиалогов, а также обмена аудиосообщениями в реальном времени.

## Функционал

- Создание аудиодиалогов.
- Удаление аудиодиалогов пользователем или автоматическое удаление при длительной неактивности пользователей.
- Обмен аудиосообщениями между пользователями.

## RPC запросы

```protobuf
service AudioDialogService {
  rpc CreateAudioDialog(CreateAudioDialogRequest) returns (CreateAudioDialogResponse) {}
  rpc DeleteAudioDialog(DeleteAudioDialogRequest) returns (DeleteAudioDialogResponse) {}
}
```

Подробнее в файле `proto/audiodialog.proto`.

## HTTP запросы

Запросы принимаются только по пути `/exchangeaudio` на порту `8080`.

Тело запроса должно содержать:
- `"dialog_id"`: ID диалога
- `"user_id"`: ID пользователя в диалоге
- `"message"`: байты аудиосообщения

Тело ответа содержит:
- `map`, где ключ — это ID пользователя, а значение — список структур аудиосообщений;
- структуры аудиосообщений содержат: `"time"` — время в формате Unix, `"audio"` — байты аудиосообщения.

## Порты

Для корректной работы необходимо открыть порты:
- `8080` — для внешних REST-запросов;
- `8086` — для взаимодействия между сервисами через gRPC.
